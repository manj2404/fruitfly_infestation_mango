Project Titleதிட்டத் தலைப்பு

Temperature-Based Phenology Model for Oriental Fruit Fly Detection in Mango

மாம்பழத்தில் ஓரியண்டல் பழ ஈ கண்டறிதலுக்கான வெப்பநிலை அடிப்படையிலான மாதிரி

Objectiveநோக்கம்

Help mango farmers spot fruit fly infestation early and know the pest's likely life stage, so control measures land at the right time.

மாம்பழ விவசாயிகள் பழ ஈ தாக்குதலை முன்கூட்டியே கண்டறிந்து, பூச்சியின் வளர்ச்சி நிலையை அறிந்து, சரியான நேரத்தில் கட்டுப்பாட்டு நடவடிக்கை எடுக்க உதவுகிறது.

Methodologyமுறை

A model checks the image is a mango, then flags it healthy or infected. The farmer's device location is used to automatically fetch today's max/min temperature, which feeds a Growing Degree Days (GDD) calculation that estimates the pest's stage and drives the risk level shown.

படம் மாம்பழமா என சரிபார்க்கப்பட்டு, ஆரோக்கியமானதா அல்லது பாதிக்கப்பட்டதா எனக் கண்டறியப்படுகிறது. விவசாயியின் இருப்பிடத்தைப் பயன்படுத்தி இன்றைய வெப்பநிலை தானாகப் பெறப்பட்டு, GDD கணக்கீடு மூலம் பூச்சியின் நிலை மதிப்பிடப்படுகிறது.

Weather Data Sourceவானிலை தரவு மூலம்

Temperature is fetched automatically from the farmer's GPS location using the Open-Meteo weather API (no manual entry needed). If location access is unavailable, temperatures can be entered manually as a fallback.

விவசாயியின் GPS இருப்பிடத்தைப் பயன்படுத்தி Open-Meteo வானிலை API மூலம் வெப்பநிலை தானாகப் பெறப்படுகிறது. இருப்பிடம் கிடைக்கவில்லை என்றால், வெப்பநிலையை நேரடியாக உள்ளிடலாம்.

GDD FormulaGDD சூத்திரம்

GDD = ((T_max + T_min) / 2) − Base Temperature (10°C)
