Project Title

Temperature-Based Phenology Model for Oriental Fruit Fly Detection in Mango

Objective

To build an accessible, AI-assisted tool that helps mango farmers detect Oriental fruit fly infestation early and understand the pest's likely life stage, so that control measures can be applied at the right time.

Methodology

A convolutional neural network verifies the uploaded image is a mango, then a second model classifies it as healthy or infected. Daily maximum and minimum temperatures are used to calculate Growing Degree Days (GDD), which estimates the pest's developmental stage and informs the risk level and recommendation shown to the farmer.

GDD Formula

GDD = ((T_max + T_min) / 2) − Base Temperature (10°C)
